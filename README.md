# Sistema Bilhete Único

Projeto desenvolvido como atividade prática de um curso de Java, com o objetivo de aplicar conceitos de Programação Orientada a Objetos.

## Sobre o projeto

O sistema simula o funcionamento de um Bilhete Único por meio de uma aplicação de linha de comando, permitindo o cadastro de usuários e bilhetes, recargas, pagamento de passagens, listagem e pesquisa por CPF.

## Funcionalidades

- Cadastro de usuários
- Cadastro de Bilhete Comum
- Cadastro de Bilhete Estudante
- Recarga de bilhetes
- Pagamento de passagem
- Listagem de bilhetes
- Pesquisa de bilhete por CPF
- Tratamento de exceções

## Conceitos aplicados

- Classes e objetos
- Encapsulamento
- Herança
- Polimorfismo
- Classes abstratas
- Construtores
- Collections (`ArrayList`)
- Tratamento de exceções (`try/catch`)
